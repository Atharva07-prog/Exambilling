# Examination Billing System (Android App)

## 📌 Project Overview
The Examination Billing System is an Android application designed to simplify the management of exam paper checking and billing processes in educational institutions.  
It helps administrators manage teachers, papers, bundles, and notifications efficiently.

---

## 🚀 Features
- 🔐 Secure Login System
- 👨‍🏫 Manage Teachers
- 👥 Manage Users
- 📄 Paper Management
- 📦 Bundle Management
- 🔔 Notification System
- 💰 Billing Management for paper checking
- 📊 Organized data storage using SQLite

---

## 🛠️ Technologies Used
- Java
- Android Studio
- XML (User Interface Design)
- SQLite Database
- Gradle Build System

---

## 📱 How the System Works
1. Admin logs into the system.
2. Admin manages teachers and users.
3. Papers are added and grouped into bundles.
4. Bundles are assigned to teachers.
5. The system tracks paper checking and billing details.
6. Notifications can be sent to users.

---

## 🔧 Installation
1. Clone the repository:
2. Open the project in **Android Studio**.
3. Sync Gradle and run the application.
